# CEGE0096 Coursework 2026/27 — Template Instructions

Read the coursework guideline (on Moodle) for the tasks, assessment, collaboration, and submission requirements. This document adds brief guidance on using the template and writing your project's README.

## Using the Template

`main.py` and `convex_hull.py` are starting placeholders. The `point.py` and `plotter.py` helpers are optional and may be adapted or replaced. Your group chooses its own project structure, classes, and interfaces.

Keep group and individual diaries in `diaries/`.

## README Requirement

Your final project must include a root-level `README.md` that introduces the application and provides enough guidance for a new user to install and use it without assistance from your group. Replace or expand the template README to reflect your completed application.

You might include the following:

- **GitHub repository URL (Mandatory):** a clearly labelled link to your group's repository.
- **Introduction:** the application's purpose, intended users, and main features.
- **Setup:** Python/environment requirements, dependencies, installation commands, and instructions for obtaining and placing the required data files.
- **User manual:** exact launch commands, required inputs and their units,   controls or options, and steps for both evacuation routing and convex-hull use.
- **Worked example and results:** an example run, how to interpret its output,   and where generated maps or CSV files are saved.
- **Troubleshooting and limitations:** common problems, remedies, and known limitations of your implementation.
- **Project overview and acknowledgements:** a short explanation of your design,   validation, sources, and any GenAI use.

Check that a new user can complete a run by following the README alone. Keep it consistent with the final application and include it in the submission ZIP.
